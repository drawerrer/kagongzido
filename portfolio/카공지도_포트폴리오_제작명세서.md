# 카공지도 포트폴리오 제작 명세서

> 첨부된 PPT 구성 초안(15슬라이드) + 콘텐츠 초안을 결합해 실제 제작용으로 정리한 문서입니다.
> 각 슬라이드마다 (1) 들어갈 내용 (2) 필요한 이미지/목업 (3) 디자인 가이드를 명시했습니다.

---

## 0-1. 슬라이드 규격

모든 페이지 크기는 동일하게 일반 PPT 규격인 **1920 x 1080px (16:9)**로 제작한다. 슬라이드마다 사이즈가 달라지지 않도록 통일하고, 이미지·목업·스크린샷도 이 캔버스 비율에 맞춰 배치한다.

---

## 0. 컬러 시스템

카공지도의 실제 브랜드 컬러(`primaryColor: #252525`)와 카페·종이·작업 분위기를 기준으로 잡았습니다. 포트폴리오 전체에 일관되게 적용하세요.

| 역할 | 컬러명 | HEX | 사용처 |
|---|---|---|---|
| Primary | Ink Black | `#252525` | 제목, 핵심 강조 텍스트 — 실제 앱 브랜드 컬러와 동일 |
| Secondary | Warm Gray | `#6B6863` | 본문, 캡션, 슬라이드 번호 |
| Background | Paper White | `#FAF9F6` | 슬라이드 배경 (순백 대신 종이 질감의 따뜻한 화이트) |
| Accent | Latte Brown | `#A47148` | 강조 박스, 인용구 보더, 핵심 수치 |
| Accent Light | Cream | `#F4ECE0` | 인용구/콜아웃 배경, 카드 배경 |
| Data Positive | Sage Green | `#6B8E5A` | 긍정 지표, "채택" 표시, 카공지도 우위 항목(○) |
| Data Negative | Muted Red | `#C17B6B` | 경쟁사 약점(X), 문제점 강조 |
| Divider | Hairline Gray | `#E3E0DA` | 구분선, 테이블 보더 |

**적용 원칙**
- 본문 텍스트는 Ink Black(#252525) 또는 Warm Gray(#6B6863)만 사용한다.
- 컬러는 의미를 가질 때만 사용한다 (긍정=Sage Green, 부정=Muted Red, 강조=Latte Brown).
- 배경은 순백(#FFFFFF) 대신 Paper White(#FAF9F6)로 통일해 카페·종이 톤을 유지한다.
- 그라데이션과 그림자는 사용하지 않는다. 플랫 디자인을 유지한다.

## 2. 슬라이드별 상세 명세

### 슬라이드 1 — 챕터 커버: 왜 카공지도였을까?

**내용**
- 대제목: "왜 카공지도였을까?"
- 하단 캡션: "카공지도는 나의 경험에서 시작됐다"
- 카공하는 분위기를 보여주는 사진 1장 (선택)

**필요 이미지**
- 카페 테이블 위 노트북·커피·콘센트가 보이는 구도 사진. 콘센트가 이 서비스의 핵심 키워드이므로 프레임 안에 자연스럽게 포함되면 좋다.
- 또는 작업 중인 인물의 뒷모습/실루엣 사진 (신원 노출 부담이 적다).

**디자인 가이드**
- 배경: Paper White(#FAF9F6)
- 제목: Ink Black, 좌측 정렬, 큰 사이즈
- 사진은 우측 또는 하단 여백에 배치하고 텍스트와 겹치지 않게 한다.

---

### 슬라이드 2 — 카공지도는 나만 찾고 싶은 게 아니었다

**내용**
- 소제목: "시장조사 결과"
- 핵심 문장: "인스타그램 #카공 해시태그 게시물은 300만 개가 넘는다. 네이버 데이터랩 기준 '카공' 검색량은 2023년 이후 안정적으로 높은 수준을 유지하고 있다."
- 이 문장을 텍스트로만 두지 말고 데이터 시각화로 대체하는 것을 권장한다.

**필요 이미지/목업**
1. 네이버 데이터랩에서 "카공" 키워드의 최근 3년 검색량 트렌드를 직접 캡처한 스크린샷.
2. 인스타그램에서 #카공 해시태그 검색 결과의 게시물 수(300만+)가 보이는 화면 캡처.
3. 위 데이터를 재구성한 라인 그래프 (실제 캡처가 어렵거나 더 정돈된 비주얼이 필요할 때 대체용으로 사용).

**디자인 가이드**
- 큰 숫자(300만+)는 Latte Brown으로 강조, 나머지 텍스트는 Warm Gray.
- 그래프 라인 컬러는 Latte Brown(#A47148), 배경은 Cream(#F4ECE0) 톤의 격자.
- 스크린샷을 사용할 경우 브라우저 크롬(주소창 등)을 잘라내고 콘텐츠 영역만 노출한다.

---

### 슬라이드 3 — 나만 카공카페 찾는 게 어려운가?

**내용**
- 소제목: "설문조사 결과"
- 페인포인트 2가지:
  1. 콘센트/좌석 수 같은 구체적 정보를 알지 못한다.
  2. 광고/협찬 때문에 진짜 경험이 담긴 리뷰를 찾지 못한다.

**필요 이미지/목업**
- 직접 진행한 설문조사 결과 캡처 (Google Forms, 타이핑 등의 응답 분포 차트).
- 설문 응답자 수, 응답 비율이 보이는 화면.
- 설문이 없다면: 위 페인포인트 2가지를 카드 2개로 시각화 (아래 목업 참고).

**디자인 가이드**
- 페인포인트 카드는 Cream 배경 + Muted Red 텍스트로 "문제"임을 시각적으로 표시.
- 카드 안에 아이콘(콘센트, 광고 차단 등)을 넣어 직관성을 높인다.

---

### 슬라이드 4 — 경쟁사 조사

**내용 (PNG 문서 기반)**
- 소제목: "네이버 지도, 블로그, 카카오맵 등 표 나열"
- 핵심 인사이트: "사용자들은 하나의 서비스로 카공지도의 조건을 만족시키지 못하고 여러 서비스를 통해 조건을 만족하게 된다. 그래서 카공지도를 탄생시키게 됐다."
- 비교 표: 네이버 지도 / 인스타그램 / 카카오맵 / 블로그 / 카공지도
  - 행: 점유율, 위치, 좌석, 콘센트, 큐레이션
- 포지셔닝 도식: "지도의 정확성 + 블로그의 정성 + 카공러를 위한 핵심 정보 = 카공지도"

**필요 이미지/목업**
- 경쟁사 비교 표 (이미 PNG 초안에 디자인이 있으므로 톤만 새 컬러 시스템으로 교체)
- 포지셔닝 다이어그램 (덧셈 구조: 지도 정확성 + 블로그 정성 + 카공 핵심 정보 = 카공지도)

**디자인 가이드**
- 표에서 ○(카공지도 우위)는 Sage Green, X(약점)는 Muted Red, △는 Warm Gray로 표시.
- 카공지도 컬럼은 다른 컬럼과 구분되도록 Cream 배경으로 하이라이트.
- 포지셔닝 도식의 "+" 기호는 Latte Brown.

---

### 슬라이드 5 — 인사이트 (우리는 카공지도를 이렇게 만들 거예요)

**내용**
- 소제목: "인사이트 + 목표(KPI)"
- 인사이트 3가지:
  1. 매장을 확인했을 때 갈지 말지를 30초 안에 결정할 수 있도록 정보를 제공한다.
  2. 내 주변의 카페를 탐색할 수 있는 위치 기반 지도와, 새로운 매장 탐색을 위한 큐레이션을 통해 사용자에게 두 가지 선택지를 제공한다.
  3. 내 취향에 맞는 카페를 발견했을 때 차곡차곡 수집할 수 있도록 저장소를 제공한다.

**필요 이미지/목업**
- 인사이트 3개를 카드 3개로 배치 (숫자 배지 1·2·3 + 짧은 제목 + 설명).
- 각 인사이트 옆에 대응하는 기능 아이콘 (시계=빠른 결정, 지도/별=탐색, 북마크=저장).

**디자인 가이드**
- 카드는 동일한 너비로 가로 배치, 배경은 Paper White, 보더는 Hairline Gray.
- 숫자 배지는 Latte Brown 배경 + Cream 텍스트.

---

### 슬라이드 6 — 플로우 + 페인포인트

**내용**
- 소제목: "유저 플로우 + 페인포인트를 믹스해서 작성"
- 카공지도 핵심 사용자 플로우를 단계별로 시각화하고, 각 단계에서 발생할 수 있는 페인포인트를 함께 표기한다.

**권장 플로우 구조**
앱 진입 → 토스 로그인 → (닉네임 미설정 시) 닉네임 설정 → 메인 지도 진입 → 필터 적용 → 카페 마커 탐색 → 카페 상세(하프→풀) → 즐겨찾기/모음집 저장

**필요 이미지/목업**
- 위 플로우를 가로 또는 세로 플로우 다이어그램으로 시각화.
- 각 단계 아래에 작은 텍스트로 페인포인트 표기 (예: "필터 적용" 단계 아래 "필터 조합 시 결과 없음 화면 미흡").

**디자인 가이드**
- 플로우 단계는 사각형 노드 + 화살표, 노드 배경은 Paper White, 보더는 Hairline Gray.
- 페인포인트는 Muted Red 텍스트로 노드 하단에 작게 표기.
- 핵심 분기점(닉네임 설정, 필터)은 Cream 배경으로 강조.

---

### 슬라이드 7 — 브랜딩 (로고, 컴포넌트, 컬러)

**내용**
- 소제목: "브랜딩 & 디자인시스템"
- 카공지도 로고
- 컬러 팔레트 (본 명세서 0번 섹션의 컬러 시스템 활용)
- 핵심 컴포넌트 (버튼, 필터 칩, 바텀싯, 카드 등)
- 타이포그래피 (제목/본문 폰트 및 사이즈)

**필요 이미지/목업**
- 카공지도 로고 이미지 (`/src/assets/LOGO/` 폴더 내 실제 로고 파일 사용)
- 컬러 팔레트 스와치 (HEX 코드와 함께)
- 컴포넌트 라이브러리 캡처: 필터 바, 바텀싯, 카페 카드, 버튼 상태(기본/선택/비활성)

**디자인 가이드**
- 컬러 스와치는 정사각형 또는 원형 칩으로 표시하고, 각 칩 아래 컬러명 + HEX 코드 기입.
- 컴포넌트는 실제 앱에서 캡처한 스크린샷을 그리드로 배치 (2x2 또는 3x2).

### 슬라이드 8 — 홈 / 상세페이지 / 가이드북 / 모음집 / 어드민

**내용**
- 소제목: "브랜딩 & 디자인시스템" (오타로 추정 — "핵심 화면"으로 수정 권장)
- 카공지도의 5개 핵심 화면을 한 슬라이드에 모아 보여준다: 홈(MapPage), 상세페이지(CafeDetailPage), 가이드북(GuidebookPage), 모음집(CollectionDetailPage), 어드민(시스템 강조)

**필요 이미지/목업**
- 실기기 또는 시뮬레이터에서 캡처한 5개 화면 스크린샷
  - 홈: 지도 + 필터 바 + 마커
  - 상세페이지: 하프 시트 상태의 카페 정보
  - 가이드북: 카공 에티켓/꿀팁 카드 리스트
  - 모음집: 모음집 상세 화면 (포함된 카페 목록)
  - 어드민: Supabase 대시보드 또는 어드민 페이지 (제보 관리 등) — "시스템 강조"이므로 데이터 구조가 보이는 화면이 좋다.

**디자인 가이드**
- 5개 화면을 모바일 프레임(베젤)에 넣어 동일한 크기로 정렬.
- 각 화면 아래 1줄 캡션으로 핵심 기능 설명.
- 어드민 화면은 나머지 4개와 톤을 구분 (예: 배경을 약간 어둡게 하거나 "System" 배지 부착)해 "사용자 화면이 아닌 운영 화면"임을 표시.

### 슬라이드 9 — 배포 프로세스

**내용 (PDF 초안에 이미 텍스트 있음)**
```
배포 프로세스
1. npm run build — Vite 빌드, kagongzido.ait 생성
2. 앱인토스 콘솔 → 버전 관리 → .ait 파일 업로드
3. 검수 제출 → 앱인토스 심사 → 배포 승인
4. 라이브 사용자에게 즉시 반영 (별도 앱 업데이트 불필요)
```

**필요 이미지/목업**
- 위 4단계를 파이프라인 다이어그램으로 시각화 (단계별 아이콘: 빌드=코드, 업로드=클라우드, 심사=체크리스트, 배포=로켓 또는 휴대폰)
- (선택) 앱인토스 콘솔의 실제 버전 관리 화면 캡처

**디자인 가이드**
- 4단계를 가로 플로우로 배치, 화살표로 연결.
