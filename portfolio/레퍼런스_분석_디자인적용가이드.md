# 포트폴리오 레퍼런스 분석 — 디자인 적용 가이드

> 캡처한 3개 레퍼런스(Cultive, the Rook, Apple iPhone 17 Pro)를 분석해, 카공지도 포트폴리오에 바로 적용할 수 있는 디자인 패턴으로 정리한 문서입니다. 기존 컬러 시스템·슬라이드 명세서와 함께 사용하세요.

---

## 1. Cultive (Behance — 앱 브랜딩 케이스 스터디)

### 관찰된 패턴

| 요소 | 내용 |
|---|---|
| 색상 사용 | 보라(Cultive 메인) + 라임 그린 + 오렌지/코랄을 풀블리드 컬러 블록으로 사용. 사진은 흑백/덤프 톤으로 처리해 컬러 블록과 대비시킴 |
| 섹션 구분 | 풀블리드 컬러 배경 섹션(보라/3색 블록)과 화이트 여백 섹션이 번갈아 등장 — 리듬감 있는 스크롤 경험 |
| 문제 정의 표현 | 3개의 컬러 카드(보라/그린/오렌지)에 각각 한 문장씩 핵심 문제를 적어 나란히 배치 |
| 인터뷰/페르소나 | 채팅 말풍선 형태의 카드 안에 사용자 인용구를 배치, 옆에 일러스트/사진 인물 아이콘 |
| 디바이스 목업 | 폰을 손에 쥔 사진 위에 화면 UI를 합성. 실제 사용 맥락(소파, 침대)에서 촬영한 라이프스타일 사진과 UI 스크린샷을 교차 배치 |
| 타이포 | 로고/타이틀은 매우 큰 산세리프 볼드체, 본문은 작은 사이즈로 컬러 블록과 대비되는 화이트/블랙 |

### 카공지도 적용 아이디어

- **슬라이드 3 (페인포인트)**: Cultive의 3색 카드처럼, 설문 페인포인트 2가지를 컬러 블록 카드로 만들되 카공지도 컬러 시스템의 Cream(#F4ECE0)·Muted Red(#C17B6B) 톤으로 절제해서 적용 (Cultive처럼 비비드한 보라/라임은 카공지도 톤과 안 맞음 — 톤만 차용, 채도는 낮춤)
- **슬라이드 1, 15 (커버)**: 풀블리드 사진 위에 로고/타이틀을 큰 볼드 타이포로 얹는 구성. 카공지도 로고를 카페 사진 위에 오버레이
- **슬라이드 3 (설문 인용)**: Cultive의 인터뷰 말풍선 카드 형식을 차용해, 카공족 인터뷰/설문 응답을 말풍선 형태로 배치하면 "1인칭 스토리"가 더 생생해짐
- **슬라이드 8 (핵심 화면)**: 단순 스크린샷 나열보다 "손에 쥔 폰 + 화면 UI" 합성 목업을 1~2개 섹션에 적용하면 실사용 맥락이 살아남

### 주의할 점

Cultive는 비비드 컬러 블록이 핵심인데, 카공지도는 차분한 카페 톤(Paper White, Latte Brown)이 정체성입니다. **컬러 블록의 "구조"(풀블리드 섹션 전환, 컬러로 챕터 구분)는 차용하되, 색 자체는 카공지도 팔레트로 교체**하는 것이 핵심입니다.

## 2. the Rook (Behance — 패션 브랜드 케이스 스터디)

### 관찰된 패턴

| 요소 | 내용 |
|---|---|
| 색상 사용 | 블랙/화이트 기본 + 오렌지·그린을 포인트로 제한적 사용. 컬러 블록이 "도장/스티커"처럼 작게 등장 |
| 레이아웃 | 사진을 비스듬히 기울여 배치(콜라주 느낌), 텍스트는 사진과 겹치지 않고 여백에 작게 배치 |
| 브랜드 시스템 섹션 | 로고 마크의 그리드 시스템(타이포 해부)을 보여주는 섹션 — "Rr Rr" 같은 대형 타이포 비교 |
| 무드보드 | 인물 사진 3장을 나란히 배치해 브랜드 톤앤매너 전달 |
| 패턴/텍스처 | 반복되는 아이콘(인물 실루엣)을 띠 형태로 배치해 섹션 구분선처럼 사용 |
| 제품 사진 | 실제 패키징/태그/굿즈를 테이블 위에 놓고 촬영한 플랫레이 사진 |

### 카공지도 적용 아이디어

- **슬라이드 7 (브랜딩)**: the Rook의 "로고 그리드/타이포 해부" 섹션처럼, 카공지도 로고의 제작 과정이나 그리드 시스템을 보여주는 섹션을 추가하면 브랜딩 슬라이드의 깊이가 생김
- **슬라이드 1 (커버)**: the Rook의 "기울어진 콜라주" 방식으로, 앱 스크린샷을 살짝 기울여 겹쳐 배치하면 딱딱한 직사각형 나열보다 생동감 있음
- **반복 아이콘 띠**: the Rook의 인물 실루엣 띠처럼, 카공 조건 아이콘(콘센트·와이파이·주차·조용함)을 반복 패턴으로 만들어 섹션 구분선에 사용하면 카공지도만의 비주얼 모티프가 됨
- **슬라이드 12 (산출물)**: the Rook의 플랫레이 사진처럼, 실제 작성한 기능명세서(종이/노트)를 책상 위에 놓고 촬영하면 "디자이너가 직접 쓴 문서"라는 점이 시각적으로 강조됨

### 주의할 점

the Rook은 패션 브랜드 특유의 "예술적 콜라주"가 강한데, 포트폴리오는 가독성이 우선입니다. 콜라주/기울임 요소는 **커버나 챕터 전환 슬라이드 1~2곳에만 제한적으로 사용**하고, 본문 슬라이드는 정렬된 그리드를 유지하세요.

## 3. Apple iPhone 17 Pro (제품 랜딩 페이지)

### 관찰된 패턴

| 요소 | 내용 |
|---|---|
| 색상 사용 | 다크 배경(블랙/딥그레이) + 제품 컬러(오렌지, 실버, 딥블루)가 그 위에서 선명하게 부각 |
| 카피 구조 | 큰 헤드라인 한 줄(예: "압도적인 강력함") + 작은 보조 설명 한 줄. 카피가 매우 짧고 단정적 |
| 제품 강조 기법 | 단일 오브젝트(폰)를 중앙에 배치하고 배경은 완전히 비움 — 제품에 시선 집중 |
| 기능 설명 | 열화상 이미지, 단면도(Unibody 구조) 등 "보이지 않는 것을 시각화"하는 다이어그램 활용 |
| 비교 표 | 모델 간 사양 비교를 깔끔한 표로 정리, 표 안에서도 색상 최소화 |
| 사용 맥락 사진 | 제품을 사용하는 사람의 라이프스타일 사진을 풀블리드로 배치해 감성 환기 |
| 여백 | 한 슬라이드(섹션)에 하나의 메시지만. 텍스트와 이미지 사이 여백이 매우 큼 |

### 카공지도 적용 아이디어

- **헤드라인 카피 구조**: 모든 슬라이드 제목을 Apple처럼 "한 문장, 단정적, 굵게"로 재작성. 예: "콘센트 있나요?" → "묻지 않아도 되는 카페" 식의 임팩트 있는 한 줄 + 보조 설명 한 줄
- **슬라이드 9 (배포 프로세스)**: Apple의 "단면도/구조 시각화"처럼, 배포 파이프라인을 단순 텍스트가 아니라 시각적 단계 다이어그램으로 — 이미 명세서에 반영되어 있음, 컬러를 더 절제할 것
- **슬라이드 13 (QA 사례)**: Apple의 열화상 이미지처럼 "보이지 않는 문제를 시각화"하는 접근 — iOS safe area 문제를 실제 화면에 빨간 영역으로 오버레이 표시하면 직관적
- **슬라이드 10 (지표)**: Apple 비교 표처럼 색상 최소화, 숫자 자체가 주인공이 되도록 여백을 충분히 둘 것
- **여백 원칙**: 현재 명세서의 슬라이드들은 정보량이 많은 편(특히 4, 12). Apple처럼 "한 슬라이드 = 한 메시지" 원칙을 적용해 정보가 많은 슬라이드는 2개로 분할 검토

### 주의할 점

Apple의 다크 배경 + 단일 오브젝트 강조는 카공지도의 Paper White 톤과 정반대입니다. **다크 배경을 그대로 가져오지 말고, "여백의 양"과 "카피의 단정함"만 차용**하세요. 단, 슬라이드 13(QA 디버그 사례)처럼 "기술적 깊이"를 보여주는 슬라이드 1곳 정도는 다크 배경 + 코드/다이어그램으로 톤을 전환해 포트폴리오에 리듬을 주는 것도 고려할 수 있습니다.

## 4. 종합 — 3개 레퍼런스에서 공통적으로 가져올 것

1. **풀블리드 섹션 전환**: 컬러/사진을 화면 끝까지 채운 섹션과 화이트 여백 섹션을 교차시켜 스크롤 리듬을 만든다 (Cultive)
2. **카피는 짧고 단정하게**: 모든 슬라이드 제목은 한 문장, 보조 설명은 한 줄 이내 (Apple)
3. **반복 모티프**: 카공 조건 아이콘(콘센트·와이파이·주차·조용함)을 패턴화해 섹션 구분에 활용 (the Rook)
4. **실사용 맥락 사진**: UI 스크린샷만 나열하지 말고, 손에 쥔 폰·카페 책상 위 노트 등 실제 맥락 사진을 섞는다 (Cultive, Apple)
5. **여백 우선**: 정보가 많은 슬라이드는 분할을 검토. 한 슬라이드 = 한 메시지 (Apple)

## 5. 기존 명세서 대비 수정 제안

| 슬라이드 | 기존 명세 | 레퍼런스 반영 후 제안 |
|---|---|---|
| 1 (커버) | 카페 사진 + 제목 텍스트 | 카페 풀블리드 사진 위에 카공지도 로고를 큰 볼드 타이포로 오버레이 (Cultive/Apple식) |
| 3 (페인포인트) | 카드 2개 | Cultive식 인용구 말풍선 카드로 변경 — 설문 응답을 직접 인용 |
| 4 (경쟁사 비교) | 표 + 포지셔닝 도식 한 슬라이드 | 정보량이 많으므로 표 슬라이드와 포지셔닝 도식 슬라이드로 분리 검토 (Apple식 여백 원칙) |
| 7 (브랜딩) | 로고 + 컬러 + 컴포넌트 | the Rook식 "로고 그리드/제작 과정" 섹션 추가 |
| 9 (배포 프로세스) | 4단계 텍스트 다이어그램 | 기존 구조 유지, 컬러는 1색만 사용해 절제 (Apple식) |
| 13 (QA 사례) | 문제-원인-해결 카드 | 실제 화면 캡처에 문제 영역을 컬러로 오버레이 표시 (Apple 열화상식) — 포트폴리오 내 유일한 다크 톤 섹션으로 고려 가능 |
| 전체 구분선 | 단순 divider | 카공 조건 아이콘 반복 패턴 띠로 교체 (the Rook식) |

## 6. 적용 시 우선순위

1. 카피 단정화 (Apple식) — 모든 슬라이드, 비용 거의 없음
2. 아이콘 반복 패턴 구분선 (the Rook식) — 1개 만들어 전체 재사용 가능
3. 인용구 말풍선 카드 (Cultive식) — 슬라이드 3에 우선 적용
4. 풀블리드 커버 (Cultive/Apple식) — 슬라이드 1, 15
5. 정보량 분할 검토 (Apple식) — 슬라이드 4, 12부터 점검
